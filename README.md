# 자막 다듬기 (subclean)

외부 네트워크·AI 없이 기기 안에서만 자막(.srt .vtt .lrc .txt) 대사를 다듬는 안드로이드 앱.
인터넷 권한이 아예 없다. 한국어 / 중국어(간체·번체) / 일본어 / 영어 자막을 다룬다.

## 기능
- 치환 규칙 (규칙 탭): 찾을 말 -> 바꿀 말. 정규식 옵션, 켜기/끄기, 검색, TSV 가져오기/내보내기
  - 일반 규칙은 전부 한 번에 적용한다. 긴 말이 우선이고 `A->B`, `B->C` 같은 연쇄는 일어나지 않는다.
  - 정규식 규칙은 그 뒤에 목록 순서대로 적용한다.
- 조사 보정 (설정 탭, 기본 켜짐): 치환한 말 바로 뒤의 조사를 새 말의 받침에 맞춘다. `철수가` 를 `민철` 로 바꾸면 `민철이`.
  이/가 은/는 을/를 과/와 (으)로 (이)랑 (이)나 (이)라 아/야 예요/이에요. 일반 규칙만 대상이고 정규식 규칙은 아니다.
  `철수가방`, `철수이야기` 처럼 조사 뒤에 한글이 더 붙는 경우는 낱말의 일부로 보고 건드리지 않는다.
- 반복 압축 (설정 탭): 같은 글자/기호 N번 이상 (ㅋㅋㅋㅋㅋ -> ㅋㅋ), 같은 단어 N번 이상 (응 응 응 응 응 -> 응 응).
  숫자는 압축하지 않는다. 기본 N=5, 남길 개수=2.
- 미리보기: 바뀌는 줄만 전/후로 보고, 마음에 들면 저장한다 (다른 이름으로 저장 / 원본에 덮어쓰기).
- 결과 전체 보기: 저장(다른 이름/덮어쓰기) 직후 바뀐 전체 텍스트가 뜬다. 길게 눌러 일부 선택·복사하거나 '전체 복사' 버튼으로 한 번에 복사한다. 저장 전에도 '결과 전체 보기' 로 볼 수 있다.
- 타임스탬프, 번호, 헤더, 빈 줄, 줄바꿈 문자(CRLF/LF)는 한 글자도 바꾸지 않고 대사 본문만 바꾼다.
- 인코딩 자동 감지: UTF-8/16(BOM), CP949, GB18030, Big5, Shift_JIS, EUC-JP. 틀리면 화면에서 직접 고른다.
  저장할 때는 원래 인코딩/BOM 으로 되돌린다 (표현 못 하는 글자가 생기면 UTF-8 로 저장하고 알려 준다).

## 빌드
- GitHub Actions: 저장소에 올리면 `.github/workflows/build.yml` 이 app-debug.apk 를 만든다 (mplater 와 같은 방식).
- 또는 Android Studio 에서 열어 빌드.

## 구조 (app/src/main/java/com/ss2ux/subclean)
- Encoding.kt     인코딩 감지 / 읽기 / 쓰기
- SubtitleDoc.kt  파일을 줄 단위로 나눠 "대사 줄"만 표시 (SRT/VTT/LRC/TXT)
- Cleaner.kt      치환 + 반복 압축 엔진 (UI 와 무관한 순수 로직)
- Josa.kt         치환 뒤 조사 보정 (받침에 맞춰 이/가 등을 고침)
- RuleStore.kt    규칙(JSON 파일)과 설정 저장, TSV 변환
- AppViewModel.kt 상태, 파일 열기/저장, 미리보기 계산
- Screens.kt      다듬기 / 규칙 / 설정 화면
- MainActivity.kt 진입점, 쓰기 권한까지 요청하는 파일 선택기
