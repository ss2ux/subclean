# 자막 다듬기 (subclean)

외부 네트워크·AI 없이 기기 안에서만 자막(.srt .vtt .lrc .txt) 대사를 다듬는 안드로이드 앱.
인터넷 권한이 아예 없다 (DeepL 버튼은 DeepL 앱으로 글을 보내는 것). 저장소 권한은 '원본 백업' 한 가지 용도로만 '모든 파일 접근'을 쓰고 설정 탭에서 끌 수 있다. 한국어 / 중국어(간체·번체) / 일본어 / 영어 자막을 다룬다.

## 기능
- 치환 규칙 (규칙 탭): 찾을 말 -> 바꿀 말. 정규식 옵션, 켜기/끄기, 검색, TSV 가져오기/내보내기, 말투 태그
  - 일반 규칙은 전부 한 번에 적용한다. 긴 말이 우선이고 `A->B`, `B->C` 같은 연쇄는 일어나지 않는다.
  - 정규식 규칙은 그 뒤에 목록 순서대로 적용한다.
- 말투 (다듬기 탭 위쪽 칩 `공통만 | 높임1 | 높임2 | 반말`, 마지막 선택을 기억): 규칙마다 말투 태그(공통/높임1/높임2/반말)가 있고, 고른 말투 + 공통 규칙만 적용한다.
  - 높임1: 화자 연상 · 청자 연하 (존대 표현을 쓰는 상황)
  - 높임2: 화자 연하 · 청자 연상 (전형적인 해요체 존댓말)
  - 기존 규칙은 전부 `공통` 이라 동작이 그대로다. 이전 버전의 JSON/TSV 도 그대로 열린다.
  - 기본 규칙 묶음(앱 안 `res/raw/speech_pack.tsv`)은 **앱을 처음 켤 때 자동으로** 규칙 목록 끝에 들어간다. 앱 업데이트로 팩 버전(`SPEECH_PACK_VERSION`, 지금 3)이 올라가면 새 규칙만 다시 추가한다. 이미 있는 규칙·기존 규칙은 건드리지 않는다. 추가된 규칙도 일반 규칙처럼 고치고 끌 수 있다.
  - 고른 말투(높임/반말)에 규칙이 하나도 없으면 다듬기 탭에 안내 문구가 나온다.
  - 규칙 탭의 말투 필터 탭(전체/공통/높임1/높임2/반말/정규식만)은 가로로 밀어서 넘긴다.
  - **똑같은 규칙(찾을 말·바꿀 말·정규식 여부·말투가 한 글자도 안 다름)은 다시 등록되지 않는다.** 이미 저장돼 있던 중복은 앱을 켤 때 맨 앞 하나만 남기고 정리한다(하나라도 켜져 있었으면 켜진 채로).
  - 높임2 = 반말/한다체를 해요체로 통일 (나->저, 내->제, 너->당신(너는->당신은, 너를->당신을, 네가->당신이, 너무/너희/너머는 그대로), 해->해요, 먹어->먹어요, 야->예요, 줘->주세요, 했다->했어요 ...). `나->저` 는 나 자신일 때만 바꾼다: `그러나 나이 나라 나가` 는 그대로. 기존 `H` 플래그 규칙은 높임2로 읽힌다.
  - 반말 = 존댓말/합쇼체를 해체로 통일 (저->나, 제->내, 해요->해, 합니다->해, 이에요->이야, 주세요->줘 ...). `저 사람, 저기요, 여보세요` 는 그대로.
  - `...` / `…` 가 들어 있는 줄은 독백으로 보고 높임/반말 규칙을 적용하지 않는다 (공통 규칙은 그대로 적용). `나는 그만할래...` 는 그대로 남는다.
  - 파일 열기는 다운로드 폴더에서 시작한다.
  - 반말에는 당신->너 도 있다 (당신은->너는, 당신이->네가, 당신을->너를, 당신들->너희).
  - 이미 맞는 말투인 문장은 건드리지 않는다. 형태소 분석이 없는 규칙 기반이라 완벽하지 않으니 미리보기로 확인한다.
  - 정규식 찾을 말에서 `{받침} {무받침} {ㄹ받침} {ㄴ받침} {ㅆ받침} {양성받침}` 약속어로 받침 있는/없는 글자를 가리킬 수 있다 (예: `(?<={받침})이야`).
  - TSV 옵션: `R`=정규식, `H1`=높임1, `H2`=높임2, `H`=예전 높임(→높임2), `C`=반말, `-`=꺼짐 (예: `RH2`, `RH1-`).
- 규칙 탭 정렬: `정렬: 최신순 / 오래된순 / 가나다순` (기본 최신순, 마지막 선택 기억). **보기 전용**이라 저장 순서(= 정규식 적용 순서)와 내보내기 순서는 그대로다. 최신순에서는 규칙을 새로 넣으면 목록 맨 위로 올라간다.
- 스크롤바: 규칙 탭과 다듬기 탭 목록이 20줄 이상이면 오른쪽에 손잡이가 생긴다. 끌면 그 위치로 바로 이동하고, 끄는 동안 `번호 / 전체` 말풍선이 뜬다.
- 제외 단어 (설정 탭): 넣은 말은 모든 규칙·조사 보정·반복 압축이 건드리지 않는다. 쉼표로 여러 개를 한 번에 넣을 수 있다. 단어 안에 들어 있는 부분도 지킨다.
- 조사 보정 (설정 탭, 기본 켜짐): 치환한 말 바로 뒤의 조사를 새 말의 받침에 맞춘다. `철수가` 를 `민철` 로 바꾸면 `민철이`.
  이/가 은/는 을/를 과/와 (으)로 (이)랑 (이)나 (이)라 아/야 예요/이에요. 일반 규칙만 대상이고 정규식 규칙은 아니다.
  `철수가방`, `철수이야기` 처럼 조사 뒤에 한글이 더 붙는 경우는 낱말의 일부로 보고 건드리지 않는다.
- 반복 압축 (설정 탭): 같은 글자/기호 N번 이상 (ㅋㅋㅋㅋㅋ -> ㅋㅋ), 같은 단어 N번 이상 (응 응 응 응 응 -> 응 응).
  숫자는 압축하지 않는다. 기본 N=5, 남길 개수=2.
- 미리보기: 바뀌는 줄만 전/후로 보고, 마음에 들면 저장한다. 저장 버튼(다른 이름으로 저장 / 원본에 덮어쓰기)과 `바뀐 줄만 보기` / `결과 전체 보기` 는 목록 위쪽에 모여 있다. 저장하면 결과가 자동으로 클립보드에 복사되고, 저장 없이 `복사` 버튼으로도 복사한다(제외한 줄 반영. 저장 뒤에 줄을 더 제외했다면 `복사`를 다시 눌러야 클립보드가 바뀐다).
  - 목록 위에 `결과 전체 N자 (대사만 N자)` 와 `5천자 초과, 분할 필요 / 5천자 이하, 분할 불필요` 가 표시된다. 제외한 줄을 반영해서 실시간으로 바뀐다. 전체는 타임스탬프·줄바꿈까지 포함한 복사되는 글자 수이고, 대사만은 분할 탭 `열린 자막 가져오기` 와 같은 기준이다. 5천자 판정은 전체 기준.
  - 바뀌는 줄을 **누르면 목록에서 빠지고 그 줄은 바꾸지 않는다** (`제외`). `바뀐 줄만 보기`를 끄면 제외한 줄이 흐리게 보이고, 다시 누르면 포함된다. `제외 취소`로 한 번에 되돌린다. 제외 목록은 파일을 새로 열거나 다시 읽으면 비워진다.
  - 다듬기 탭 목록(빈 화면 포함)을 아래로 당기면 열어 둔 파일을 다시 읽는다. 직접 고른 인코딩은 유지한다.
- DeepL 연결: 결과가 5천자 이하이면 다듬기 탭의 `복사 후 DeepL 열기` 가 결과를 클립보드에 복사하고, 그 글을 **DeepL 앱**(`com.deepl.mobiletranslator`)으로 바로 보내 번역하게 한다. 글자를 선택했을 때 메뉴에 뜨는 'DeepL' 항목과 같은 방식(ACTION_PROCESS_TEXT)이고, 안 되면 공유 방식, 그래도 안 되면 앱만 열어 주니 붙여 넣으면 된다(복사는 항상 먼저 해 둔다). 앱이 없으면 플레이스토어의 DeepL 페이지를 연다. 5천자를 넘으면 이 버튼은 `DeepL (분할 필요)` 로 막히고, 분할 탭의 `복사 후 DeepL` 이 같은 일을 다음 조각으로 한다. 이 앱에는 인터넷 권한이 필요 없다.
- 원본 백업 (설정 탭, 기본 켜짐): `원본에 덮어쓰기` 직전에 열어 둔 파일이 있는 폴더 안에 `원본 자막` 폴더를 만들고 원본을 **한 번만** 저장한다(`.srt .vtt .lrc .txt` 모두 동일). 같은 이름의 백업이 이미 있으면 다시 저장하지 않아 처음 원본이 그대로 남고(여러 번 덮어써도 마찬가지), 이미 `원본 자막` 폴더 안에 있는 파일은 백업하지 않는다. 예전 버전이 만든 `vtt` 폴더에 같은 이름의 백업이 있어도 이미 백업된 것으로 보고 새로 만들지 않는다. 백업을 못 하면(권한 없음, 폴더 위치 못 찾음 등) 원본을 지키려고 덮어쓰지 않고 이유를 알려 준다. `다른 이름으로 저장`은 원본이 안 바뀌므로 백업하지 않는다. 파일 선택기로 연 파일은 같은 폴더에 새 폴더를 만들 권한이 없어서 '모든 파일 접근'(MANAGE_EXTERNAL_STORAGE) 허용이 필요하다(안드로이드 11 이상, 설정 탭의 `권한 허용하러 가기`).
- 인코딩 표시·변경은 설정 탭으로 옮겼다 (열어 둔 파일의 형식·인코딩 확인, 자동 감지 대신 직접 고르기).
- 결과 전체 보기: 저장(다른 이름/덮어쓰기) 직후 바뀐 전체 텍스트가 뜬다. 길게 눌러 일부 선택·복사하거나 '전체 복사' 버튼으로 한 번에 복사한다. 저장 전에도 '결과 전체 보기' 로 볼 수 있다.
- 타임스탬프, 번호, 헤더, 빈 줄, 줄바꿈 문자(CRLF/LF)는 한 글자도 바꾸지 않고 대사 본문만 바꾼다.
- 분할 탭 (5천자 넘는 텍스트를 DeepL 에 나눠 넣기): 웹앱 'DeepL Smart Splitter' 기능이 앱 안에 들어왔다. 인터넷은 쓰지 않는다.
  - 붙여 넣기, `파일 열기`(.txt 는 전부, 자막 .srt .vtt .lrc 는 대사만), `열린 자막 가져오기`(다듬기 탭에 열어 둔 자막의 다듬기 전 대사만)로 글을 넣는다.
  - 글자 수 제한 슬라이더(1000~5000, 100자 단위, 기본 4500, 마지막 값 기억). 문단 끝 > 문장 끝 > 공백 > 글자 수 순서로 자연스러운 곳에서 자른다.
  - `다음 조각 복사` 버튼이나 조각마다 있는 `복사` 로 클립보드에 복사하고, 복사한 조각은 `복사됨` 으로 표시된다. 글이나 제한을 바꾸면 복사 표시는 새로 시작한다.
  - `마지막 조각부터 복사` 스위치(기본 켜짐, 마지막 값 기억): 켜면 목록도 마지막 조각이 맨 위에 오고, `다음 조각 복사` 가 마지막 조각 → 조각 1 순서로 간다. 클립보드 기록은 나중에 복사한 게 위에 보여서, 이렇게 복사하면 붙여 넣을 때 조각 1부터 순서대로 내려가며 쓸 수 있다.
  - 다듬기 탭에서 결과를 복사하면(`복사`, `복사 후 DeepL 열기`, `결과 전체 보기`의 `전체 복사`) 복사한 글이 분할 입력칸에도 자동으로 들어간다(기존 글은 교체). 이렇게 자동으로 들어온 글은 다듬기 탭에서 **다른 파일을 열면** 자동으로 지워진다. 사용자가 입력칸을 직접 고치거나, 파일·자막을 가져오면 내 글로 보고 지우지 않는다. `저장·복사`(다른 이름으로 저장, 원본에 덮어쓰기)는 넣지 않는다.
  - 탭을 옮겨 다녀도 입력한 글과 복사 표시는 그대로 남는다.
- 인코딩 자동 감지: UTF-8/16(BOM), CP949, GB18030, Big5, Shift_JIS, EUC-JP. 틀리면 설정 탭에서 직접 고른다.
  저장할 때는 원래 인코딩/BOM 으로 되돌린다 (표현 못 하는 글자가 생기면 UTF-8 로 저장하고 알려 준다).

## 구조 (app/src/main/java/com/ss2ux/subclean)
- Encoding.kt     인코딩 감지 / 읽기 / 쓰기
- SubtitleDoc.kt  파일을 줄 단위로 나눠 "대사 줄"만 표시 (SRT/VTT/LRC/TXT)
- Cleaner.kt      치환 + 반복 압축 엔진 (UI 와 무관한 순수 로직)
- Splitter.kt    긴 글을 글자 수 제한 안으로 나누는 순수 로직 (웹앱 smartSplit 과 같은 규칙)
- Speech.kt       말투(공통/높임1/높임2/반말) 정의, 정규식용 한글 받침 묶음 약속어({받침} 등)
- Josa.kt         치환 뒤 조사 보정 (받침에 맞춰 이/가 등을 고침)
- RuleStore.kt    규칙(JSON 파일)과 설정 저장, TSV 변환
- AppViewModel.kt 상태, 파일 열기/저장, 미리보기 계산
- Screens.kt      다듬기 / 규칙 / 설정 화면
- Backup.kt       덮어쓰기 전 원본을 '원본 자막' 폴더에 1회 백업 (모든 파일 접근 권한)
- DeepL.kt        글을 DeepL 앱으로 바로 보내기 (안 되면 앱 열기, 앱이 없으면 플레이스토어)
- SplitScreen.kt  분할 화면
- res/raw/speech_pack.tsv  기본 말투 규칙 팩 (높임·반말). 정규식 순서가 중요하다
- MainActivity.kt 진입점, 쓰기 권한까지 요청하는 파일 선택기
